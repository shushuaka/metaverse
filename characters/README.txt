이 폴더에 내 도트 캐릭터 그림(PNG)을 넣어요.

- 파일 이름 = 캐릭터 이름. 예: 콩이.png
- 크기: 가로 70칸, 세로 80칸 안 (1px = 도트 1칸). 작은 그림은 화면에서 2배, 3배로 키워 보여 줘요.
- 바깥은 투명하게.
- 표정과 동작은 따로 넣을 수 있어요 (없으면 앞모습으로):
    콩이_happy.png  기쁠 때 (결재 승인, 인사)
    콩이_sad.png    속상할 때 (일이 늦어질 때, 결재를 기다릴 때)
    콩이_walk.png   걸을 때
    콩이_rest.png   라운지에서 쉴 때
- AI로 받은 큰 그림은 skills 폴더의 도트 캐릭터 스킬(pixel-character)로 바꾸면 이 규격으로 여기에 저장돼요.

넣고 나서 사무실 화면을 새로고침하면 바로 보여요.
